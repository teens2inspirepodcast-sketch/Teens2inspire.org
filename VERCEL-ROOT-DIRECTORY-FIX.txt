Teens2Inspire.org — Vercel Root Directory Fix

The supplied website source files (including package.json) are located at the ZIP/repository root.

In Vercel, open the teens2inspire.org project → Settings → Build and Deployment → Root Directory.
Set the Root Directory to the repository root (usually leave the field blank or use ".", depending on the UI).
Do NOT use "teens2inspire-website" unless that exact folder exists in the connected Git repository.
Save the setting and redeploy.

This is a Vercel project setting; adding a code file cannot override a missing Root Directory folder.
